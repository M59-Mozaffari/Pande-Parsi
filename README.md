
### 📱 Pand-e-Parsi | پند پارسی

### 🇬🇧 Project Overview (English)

### ✨ Features

* [x] **Ever-Growing Library:** Our collection of wisdom is constantly expanding! New poems and quotes are added regularly, giving you fresh content to discover.
* [x] **Vast Collection:** Access hundreds of handpicked poems and wise quotes (پند و اندرز) from iconic Persian literary masters.
* [x] **Daily Wisdom:** Get a new, inspiring quote or poem every day with our "Quote of the Day" feature.
* [x] **Powerful Search:** Easily find poems by keywords, themes, or specific poets.
* [x] **Favorites:** Bookmark your most-loved poems for quick access anytime.
* [x] **Share Inspiration:** Share beautiful verses directly with your friends and family via other social media and messaging apps.
* [x] **Elegant & Native UI:** Enjoy a user experience tailored for Persian speakers with a beautiful, native Android interface.
* [x] **Works Offline:** Once downloaded, read your favorite poems anytime, anywhere, without an internet connection.

### 🛠️ Installation & Getting Started / نحوه اجرا

To run this project locally, follow these simple steps:
برای اجرای این پروژه به صورت محلی روی سیستم خود، مراحل زیر را دنبال کنید: 

1. **Clone the repository / کلون کردن پروژه:** 

bash

git clone https://github.com/M59-Mozaffari/Pande-Parsi.git

بااحتیاط از کد استفاده کنید.
2. **Navigate to the project directory / ورود به پوشه پروژه:** 

bash

cd Pande-Parsi

بااحتیاط از کد استفاده کنید.
3. **Get dependencies / دریافت پکیج‌ها:** 

bash

flutter pub get

بااحتیاط از کد استفاده کنید.
4. **Run the application / اجرای اپلیکیشن:** 

bash

flutter run

بااحتیاط از کد استفاده کنید.
